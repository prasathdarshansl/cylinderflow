# 🚀 CylinderFlow  
### Gas Cylinder Inventory & Billing Mobile Application

CylinderFlow is a **production-ready mobile application** designed to manage **industrial and commercial gas cylinder operations**, including product catalog management, billing, inventory tracking, and invoice generation.

Built with a **mobile-first approach**, CylinderFlow replaces manual registers and spreadsheets with a **secure, scalable, and real-time solution**.

---

## ✨ Key Features

### 📦 Product & Catalog Management
- Add, edit, and delete gas products (O₂, CO₂, Argon, LPG, etc.)
- Manage pricing, tax percentage, stock count, and product images
- Real-time updates across the app

### 🧾 Smart Billing System
- Create multi-product bills for a single customer
- Serial-number tracking for each cylinder
- Apply tax and one-time deposit dynamically
- Auto-generate digital invoices

### 🔄 Inventory & Cylinder Tracking
- Track cylinders as Issued or Returned
- 100% serial-level traceability
- Automatic stock updates on sale and return

### 📊 Real-Time Dashboard
- View daily sales value
- Monitor outstanding cylinders
- Track recent returns
- Live updates using Firebase

### 📄 Invoice Generation & Sharing
- View invoice immediately after sale
- Export invoices as PDF
- Share invoices via WhatsApp, Email, Drive, etc.
- All invoices are saved and retrievable

### 🔐 Secure Authentication
- Email-based authentication
- Protected routes and session handling
- Cloud-backed data persistence
